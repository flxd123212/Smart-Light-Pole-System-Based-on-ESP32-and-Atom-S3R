# 智能灯杆系统 —— 数据库设计文档

## 一、概述

本数据库用于支持**基于物联网的智能灯杆系统**，涵盖灯杆管理、传感器数据采集、设备管理、报警规则与记录、远程控制日志、摄像头抓拍及AI识别结果存储等核心功能。

系统采用 **MySQL** 作为关系型数据库，共设计 **7张核心表**，遵循若依（RuoYi）框架的代码生成规范，可直接导入生成完整的后台增删改查代码及前端页面。

---

## 二、表结构详细说明

### 1. 灯杆表（iot_pole）

**用途**：存储智能灯杆的基本信息与状态。

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
|--------|------|--------|--------|------|
| pole_id | bigint(20) | NOT NULL | 自增 | 灯杆主键ID |
| pole_code | varchar(50) | NOT NULL | - | 灯杆编号（唯一） |
| pole_name | varchar(100) | YES | '' | 灯杆名称 |
| location | varchar(200) | YES | '' | 安装位置描述 |
| latitude | decimal(10,6) | YES | NULL | 纬度坐标 |
| longitude | decimal(10,6) | YES | NULL | 经度坐标 |
| status | char(1) | YES | '0' | 状态：0正常 / 1离线 / 2故障 |
| led_status | char(1) | YES | '0' | LED灯状态：0关闭 / 1开启 |
| order_num | int(4) | YES | 0 | 显示排序号 |
| del_flag | char(1) | YES | '0' | 删除标志：0存在 / 2删除 |
| create_by | varchar(64) | YES | '' | 创建者 |
| create_time | datetime | YES | NULL | 创建时间 |
| update_by | varchar(64) | YES | '' | 更新者 |
| update_time | datetime | YES | NULL | 更新时间 |
| remark | varchar(500) | YES | NULL | 备注信息 |

**索引**：
- 主键：`pole_id`
- 唯一索引：`uk_pole_code`（pole_code）

---

### 2. 传感器数据表（iot_sensor_data）

**用途**：记录每个灯杆上传的实时传感器数据。

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
|--------|------|--------|--------|------|
| data_id | bigint(20) | NOT NULL | 自增 | 数据主键 |
| pole_id | bigint(20) | NOT NULL | - | 所属灯杆ID |
| temperature | decimal(5,1) | YES | NULL | 温度（℃） |
| humidity | decimal(5,1) | YES | NULL | 湿度（%RH） |
| illumination | decimal(8,1) | YES | NULL | 光照强度（lx） |
| voltage | decimal(6,2) | YES | NULL | 电压（V） |
| current | decimal(6,3) | YES | NULL | 电流（A） |
| collect_time | datetime | NOT NULL | - | 数据采集时间 |
| create_by | varchar(64) | YES | '' | 创建者 |
| create_time | datetime | YES | NULL | 创建时间 |

**索引**：
- 主键：`data_id`
- 普通索引：`idx_pole_id`（pole_id）
- 普通索引：`idx_collect_time`（collect_time）

---

### 3. 设备表（iot_device）

**用途**：管理每个灯杆下挂载的具体设备信息。

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
|--------|------|--------|--------|------|
| device_id | bigint(20) | NOT NULL | 自增 | 设备主键 |
| pole_id | bigint(20) | NOT NULL | - | 所属灯杆ID |
| device_name | varchar(100) | YES | '' | 设备名称 |
| device_type | char(1) | YES | '0' | 设备类型：0温湿度 / 1光照 / 2电压电流 / 3LED灯 / 4摄像头 |
| device_model | varchar(100) | YES | '' | 设备型号 |
| status | char(1) | YES | '0' | 状态：0正常 / 1离线 / 2故障 |
| del_flag | char(1) | YES | '0' | 删除标志：0存在 / 2删除 |
| create_by | varchar(64) | YES | '' | 创建者 |
| create_time | datetime | YES | NULL | 创建时间 |
| update_by | varchar(64) | YES | '' | 更新者 |
| update_time | datetime | YES | NULL | 更新时间 |
| remark | varchar(500) | YES | NULL | 备注 |

**索引**：
- 主键：`device_id`
- 普通索引：`idx_pole_id`（pole_id）

---

### 4. 报警规则表（iot_alarm_rule）

**用途**：设定传感器参数的正常范围阈值，当数据超限时触发报警。

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
|--------|------|--------|--------|------|
| rule_id | bigint(20) | NOT NULL | 自增 | 规则主键 |
| pole_id | bigint(20) | YES | NULL | 灯杆ID（NULL表示全局规则） |
| param_type | char(1) | NOT NULL | - | 参数类型：0温度 / 1湿度 / 2光照 / 3电压 / 4电流 |
| min_value | decimal(10,2) | YES | NULL | 下限值 |
| max_value | decimal(10,2) | YES | NULL | 上限值 |
| enabled | char(1) | YES | '1' | 是否启用：0停用 / 1启用 |
| create_by | varchar(64) | YES | '' | 创建者 |
| create_time | datetime | YES | NULL | 创建时间 |
| update_by | varchar(64) | YES | '' | 更新者 |
| update_time | datetime | YES | NULL | 更新时间 |

**索引**：
- 主键：`rule_id`
- 普通索引：`idx_pole_id`（pole_id）

---

### 5. 报警记录表（iot_alarm_record）

**用途**：记录所有触发的报警事件，含处理状态跟踪。

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
|--------|------|--------|--------|------|
| record_id | bigint(20) | NOT NULL | 自增 | 记录主键 |
| pole_id | bigint(20) | NOT NULL | - | 灯杆ID |
| rule_id | bigint(20) | YES | NULL | 触发的规则ID |
| param_type | char(1) | NOT NULL | - | 报警参数类型：0温度 / 1湿度 / 2光照 / 3电压 / 4电流 / 5行人 |
| alarm_value | varchar(50) | YES | '' | 触发时的数值 |
| alarm_message | varchar(500) | YES | '' | 报警描述信息 |
| status | char(1) | YES | '0' | 处理状态：0未处理 / 1已处理 / 2已忽略 |
| handle_by | varchar(64) | YES | NULL | 处理人 |
| handle_time | datetime | YES | NULL | 处理时间 |
| handle_remark | varchar(500) | YES | NULL | 处理备注 |
| del_flag | char(1) | YES | '0' | 删除标志：0存在 / 2删除 |
| create_by | varchar(64) | YES | '' | 创建者 |
| create_time | datetime | YES | NULL | 创建时间 |

**索引**：
- 主键：`record_id`
- 普通索引：`idx_pole_id`（pole_id）
- 普通索引：`idx_create_time`（create_time）

---

### 6. 控制日志表（iot_control_log）

**用途**：记录管理人员远程控制LED灯等设备的操作日志。

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
|--------|------|--------|--------|------|
| log_id | bigint(20) | NOT NULL | 自增 | 日志主键 |
| pole_id | bigint(20) | NOT NULL | - | 灯杆ID |
| device_id | bigint(20) | YES | NULL | 设备ID |
| control_type | char(1) | NOT NULL | - | 控制类型：0开灯 / 1关灯 / 2重启 |
| result | char(1) | YES | '0' | 执行结果：0成功 / 1失败 |
| error_message | varchar(500) | YES | NULL | 错误信息 |
| create_by | varchar(64) | YES | '' | 操作人 |
| create_time | datetime | YES | NULL | 操作时间 |

**索引**：
- 主键：`log_id`
- 普通索引：`idx_pole_id`（pole_id）

---

### 7. 摄像头抓拍记录表（iot_camera_capture）

**用途**：存储视频流截图及AI行人识别结果，支持历史查询与展示。

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
|--------|------|--------|--------|------|
| capture_id | bigint(20) | NOT NULL | 自增 | 抓拍主键 |
| pole_id | bigint(20) | NOT NULL | - | 灯杆ID |
| image_url | varchar(500) | YES | '' | 原始图片存储路径 |
| person_count | int(4) | YES | 0 | 检测到的行人数量 |
| result_json | text | YES | NULL | AI识别结果JSON |
| capture_time | datetime | NOT NULL | - | 抓拍时间 |
| del_flag | char(1) | YES | '0' | 删除标志：0存在 / 2删除 |
| create_by | varchar(64) | YES | '' | 创建者 |
| create_time | datetime | YES | NULL | 创建时间 |

**索引**：
- 主键：`capture_id`
- 普通索引：`idx_pole_id`（pole_id）
- 普通索引：`idx_capture_time`（capture_time）

## 三、表关系说明

| 关联表 | 外键字段 | 关联主表 | 关联字段 | 关系说明 |
|--------|----------|----------|----------|----------|
| iot_device | pole_id | iot_pole | pole_id | 一个灯杆拥有多个设备（1:N） |
| iot_sensor_data | pole_id | iot_pole | pole_id | 一个灯杆产生多条传感器数据（1:N） |
| iot_alarm_rule | pole_id | iot_pole | pole_id | 一个灯杆可配置多条报警规则（1:N），pole_id为NULL时为全局规则 |
| iot_alarm_record | pole_id | iot_pole | pole_id | 一个灯杆有多条报警记录（1:N） |
| iot_alarm_record | rule_id | iot_alarm_rule | rule_id | 一条报警记录对应一条规则（N:1），可为空 |
| iot_control_log | pole_id | iot_pole | pole_id | 一个灯杆有多条控制日志（1:N） |
| iot_camera_capture | pole_id | iot_pole | pole_id | 一个灯杆有多条抓拍记录（1:N） |
