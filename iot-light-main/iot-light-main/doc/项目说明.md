# 基于物联网的智能灯杆系统

## 项目来源
2025年第九届湖南省大学生物联网应用创新设计竞赛 —— 技能赛题目

---

## 一、项目整体流程

1. **赛前准备**  
   - 参赛团队自备硬件（开发板、传感器、摄像头、继电器、LED灯、服务器等），提前搭建本地局域网。  
   - 可携带平时编写的代码模块入场，比赛开始后禁止与外界或其他队伍交流。

2. **系统搭建与配置**  
   - 每个灯杆部署温湿度、光照、电压电流传感器，以及LED灯和继电器。  
   - 摄像头用于视频监控和行人检测。  
   - 所有设备通过局域网连接至自备后台服务器，数据上传并存储。

3. **系统运行与数据交互**  
   - 传感器持续采集数据并上传服务器。  
   - 摄像头视频流可实时查看，并可截取图片调用组委会提供的AI识别接口（HTTP本地调用），检测行人并返回结果。  
   - Web前端或手机APP通过服务器获取实时数据、报警信息、历史记录，并发送LED控制指令。

4. **提交成果**  
   - 比赛结束前，将所有工程文件拷贝至组委会发放的U盘，并附README说明文件，供评分使用。

---

## 二、系统核心功能

| 功能模块 | 具体内容 |
|---------|----------|
| **灯杆信息展示** | 列表显示所有灯杆，点击进入详情页查看LED状态、传感数据和视频 |
| **传感参数实时监测** | 实时显示温度、湿度、光照、电压、电流，连续上传服务器 |
| **异常报警** | 设定传感器上下限，超出后在界面报警，支持报警记录查询 |
| **视频监控与行人检测** | 显示实时视频流，截取当前帧，调用HTTP接口识别行人，显示结果和人数 |
| **数据存储与查询** | 所有数据存入服务器，支持按灯杆编号和时间范围筛选，以列表和曲线图展示 |
| **远程设备控制** | 管理人员通过Web或APP远程开启/关闭LED灯 |
